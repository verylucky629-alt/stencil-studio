# Stencil Studio

흰 배경을 지우고, 사진을 스텐실(도안)로 바꿔 주는 브라우저 도구. 두 기능이 한 화면에 이어져 있다.
이미지는 서버로 올라가지 않고 기기 안에서만 처리된다. 빌드 도구도, 외부 API도, 라이브러리도 쓰지 않는다.

## 기능

- **흰 배경 제거** — 허용치, 경계 부드럽게(feather), 지울 색 지정(스포이드·자동), 체크무늬/흰색/검정 배경 미리보기, 투명 PNG 저장
- **스텐실 변환** — 윤곽선(Outline) / 도안(Adaptive) / 흑백(Threshold) 3가지 모드, 임계값·디테일·명암·선 굵기·노이즈 제거, 반전, 전사지용 좌우반전, 배경 투명
- **비교** — 원본과 결과를 한 화면에서 슬라이더로 나눠 봄
- **내보내기** — 배경만 PNG, 스텐실 PNG(화면/고해상도/최대), 브라우저 인쇄
- 모바일(iPhone)·아이패드·데스크톱 반응형, 한국어/영어, 다크/라이트 테마

## 실행

정적 파일만 있으면 된다. 로컬에서는:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`file://`로 열면 샘플 이미지·카메라 등 일부 기능이 막히므로 로컬 서버로 여는 편이 좋다.

## GitHub Pages 배포

1. 저장소를 만든 뒤 이 폴더를 그대로 푸시한다.
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/ (root)`.
3. `https://<계정>.github.io/<저장소>/` 로 열린다.

## 구조

```
index.html   화면 구조
styles.css   스타일 (다크/라이트, 반응형, 인쇄)
app.js       배경 제거·스텐실 파이프라인과 UI 로직
assets/      아이콘, 샘플 이미지
```

처리 파이프라인은 `원본 → 배경 제거(RGBA) → 스텐실(흑백 마스크) → 저장` 순서이고,
미리보기는 긴 변 1500px, 저장은 선택한 해상도(최대 원본 크기)로 다시 계산한다.
